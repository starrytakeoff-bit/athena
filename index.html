동일한 구글 시트를 중앙 저장소로 사용합니다. 기존 기록 보호를 위해 처음 연결할 때 동기화 방향을 반드시 선택하세요. 데이터 조회에는 보안 키가 사용됩니다. 사진은 기기별로 보관되며 다른 기기로 전송되지 않습니다.

아직 클라우드를 연결하지 않았습니다. 연결 전 현재 기기의 JSON 백업을 먼저 받아 주세요.

처음 연결 시 PC와 시트에 각각 기존 기록이 있다면 자동으로 덮어쓰지 않습니다. 데이터 비교 후 가져오기/내보내기를 직접 선택해야 합니다. 변경사항이 충돌하면 자동 덮어쓰기를 중단합니다. 구글 시트와 Drive 백업은 로그인된 구글 계정에 저장됩니다. 앱을 공유할 계획이라면 전송용 키를 공개하지 마세요.
